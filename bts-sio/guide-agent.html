Votre nouveau poste de travail : les bons réflexes

Votre poste est prêt. Cette page résume ce qu’il faut savoir pour bien l’utiliser et obtenir de l’aide si besoin.

Les 5 bons réflexes

  1. Verrouillez votre session dès que vous quittez votre bureau : touches Windows + L.
  2. Laissez votre poste allumé ou en veille le soir au moins une fois par semaine : c’est la nuit qu’il reçoit les mises à jour de sécurité.
  3. Fermez vos applications en fin de journée, en particulier le navigateur : une mise à jour peut échouer si l’application est restée ouverte.
  4. N’installez aucun logiciel vous-même : faites une demande d’assistance, nous l’installerons s’il est autorisé.
  5. Méfiez-vous des mails inattendus qui demandent un mot de passe ou de cliquer sur un lien. En cas de doute, ne cliquez pas et signalez-le.

Vos fichiers

  • Vos documents professionnels ont été copiés depuis votre ancien poste. Ils sont dans le dossier Documents.
  • Une copie de sauvegarde est conservée quelques mois. S’il vous manque un fichier ou une application dans les deux semaines, signalez-le : nous le récupérons.
  • Enregistrez vos fichiers de travail sur les lecteurs réseau de votre service plutôt que sur le bureau : ils sont sauvegardés, le poste ne l’est pas.

Besoin d’aide

  1. Faites une demande depuis l’application d’assistance installée sur votre poste, ou appelez l’assistance au numéro : ______________________
  2. Décrivez le problème : ce que vous faisiez, le message d’erreur exact (une capture d’écran aide beaucoup) et depuis quand.
  3. Restez joignable : un technicien peut vous rappeler ou prendre la main à distance sur votre poste, toujours avec votre accord.
