Statistiques de visite

Le site utilise GoatCounter pour compter les visites. C’est un outil de statistiques sans cookies, qui ne collecte aucune donnée personnelle et ne permet pas d’identifier les visiteurs. Pour compter une visite, votre navigateur contacte les serveurs de GoatCounter.

Hébergeur

Comme tout hébergeur, GitHub peut enregistrer l’adresse IP des visiteurs pour assurer la sécurité du service. Ce traitement relève de GitHub et de sa politique de confidentialité.

Polices de caractères

Les polices de caractères sont hébergées directement sur ce site : aucune donnée n’est transmise à un tiers pour les afficher.
