Données personnelles

Ce site ne dépose aucun cookie, n’utilise aucun outil de mesure d’audience et ne contient aucun formulaire. Il ne collecte donc aucune donnée personnelle de manière directe.

Hébergeur

Comme tout hébergeur, GitHub peut enregistrer l’adresse IP des visiteurs pour assurer la sécurité du service. Ce traitement relève de GitHub et de sa politique de confidentialité.

Polices de caractères

À compléter : héberger les polices directement sur le site pour supprimer cet échange avec Google.
